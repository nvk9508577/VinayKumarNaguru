VINAYKUMAR NAGURU PORTFOLIO — CHARCOAL & ORANGE

1. Extract this ZIP using Extract All.
2. Open the extracted folder named Vinay-Portfolio.
3. Open index.html in your browser.
4. Keep all four HTML files together in the same folder for navigation to work.

Pages:
- index.html: Main portfolio
- projects.html: Home Lab & Projects
- services.html: Infrastructure Services
- portal.html: Personal Portal

The Personal Portal links to your Cockpit, Photos and Files subdomains. Those services must be online and separately secured.
